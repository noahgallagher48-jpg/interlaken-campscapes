The files

Every frame opens full screen here, and the Open file link under it is the web file: 2560 pixels on the long edge, right for the website, email, social and slide decks. The full-resolution set, from the 45-megapixel masters, arrives with the full library within 30 days of the last on-site day.

The print-grade frames

Printing

The Fine Art and Signature frames carry production notes.

Produced through Abba Photo at Miller's

The print-grade frames are produced through me at Miller's Imaging Labs. The specs on each frame are written for that lab's papers and inks. Printed somewhere else, the spec no longer describes what ends up on the wall.

Each carries its own specs

Paper class, the size window at which the frame reads as intended, finish and mounting where it matters. Delivered alongside the full-resolution file so the frame arrives at full strength.

The notation rides with the frame

Fine-art frames publish with the line "from the fine-art series, available as a print." The line stays with the image wherever it runs, so a frame the camp has already posted is still a print someone can ask for.

Metal and acrylic300 DPIHard, reflective surfaces show detail, so these get the most resolution. Lobby and donor-wall pieces.
Photographic paper250 DPIFramed prints, gifts, anything behind glass.
Canvas150 DPIThe weave absorbs detail, so canvas goes largest from the same file. Big wall pieces.

Every frame here prints; what changes between frames is how large each one goes. Per-frame size windows ride with the specs when the full library lands.
